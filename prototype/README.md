# SidelineReel prototype (Ajaia PM assessment)
Single self-contained `index.html` — no build, no login.
- Open locally: double-click `index.html`, or `python3 -m http.server 8000` here and visit http://localhost:8000
- Flow: Roster → tap a kid → personal reel (play/pause, clip list, scrub timeline, share) → "Weekly recap" tab → choose families → Send (confirmation).
- GitHub Pages: copy is at `sidelinereel/` in repo bikramlaishram/job-application-assets → https://bikramlaishram.github.io/job-application-assets/sidelinereel/
Sample data is fictional (Harbor Hawks U12). https://ajaia.ai
